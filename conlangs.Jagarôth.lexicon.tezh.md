# tezh
: verbal suffix :: expectation + future tense

- Jagarôth has no future tense; the two tenses are past and non-past
- -tezh indicates an expected outcome: "I expect this will happen"

- example:
    - kafâlem-sis borgôdh mûmbid korodâlem-tezh
    - parse :: go.Finite.1SgSubject-If city.Dative corpse.Adjective \
               die.Finite.1SgSubject-ExpectedOutcome
    - translation :: If I go to the dead city, I expect I will die.
     
    - notes :: more typically -sis is followed by -tod "then"
        - kafâlem-sis borgôdh mûmbid korodâlem-tod
        - If I go to the dead city, then I will die.
